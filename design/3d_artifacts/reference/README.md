# Reference screenshots of the 3D pages

The visual target for the hub's 3D view (spec `claude/Hub_3D_View_Spec.md`, section 5). Taken 22 Nov 2026 in headless Chromium (SwiftShader) at deviceScaleFactor 1, with three.js served locally because the CDNs were refused, and web fonts blocked, so fallback fonts show. A view counts as matching when the same pose gives the same classes of object, materials and layout; pixel equality is not expected.
